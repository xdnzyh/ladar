# 独立距离标定方案（刹车参数冻结后执行）

## 目的和当前状态

按用户要求，刹车调节与物理标定分开进行。采用BRAKE_CAL=4的刹车参数，不再追小幅停车误差。本轮只确定8个平移方向各自的毫米/编码器计数比例，不测试旋转。

最新刹车验证：Q1200两次误差+3/+24 CNT，C600两次+36.5/+2.5 CNT。按用户要求冻结现参数；这些编码器误差不能直接当成毫米。本批日志来自保留详细输出的BRAKE_CAL=4版本；后续通信修复仍在验证，不影响本批数据登记。

## 实际完成的16次测量

每方向短、长各一次，共16次。为降低人工读数的相对误差，现场将直向长档1400改为7000 CNT，斜向长档1200改为6000 CNT；短档仍为700/600。本批全部REASON=TARGET，长档LEAD=0，实际ENC已由日志补齐。当前补偿覆盖W/S/A/D的700～1400 CNT、Q/E/Z/C的600～1200 CNT，档间插值；范围外仍未补偿。标定结论先用于这些范围，不能直接认定极短或更长动作同样准确。

## 如何量

1. 选一个固定车身基准点，优先车身中心在地面的投影。每次标记这个点的起点和停车稳定后的终点，用同一个基准点，避免把车头角点旋转造成的位移混入测量。
2. 以本次起点的车头方向建立地面坐标：向前x为正、向后x为负；向左y为正、向右y为负。车停下后仍按起点坐标量，不跟着停车后的朝向换坐标。
3. 量起终点的前后净位移x和左右净位移y，单位毫米，填表。斜移也量两个分量，现场不用计算斜边。
4. 每次重新标起点，可手动把车放回有空间的位置；先记录完本次终点再挪车。不要把连续几次累计路程当单次距离。
5. 若量具条件确实只能量起终点直线距离，写明“直线距离d”，并注明方向是否明显偏斜；正常朝向时可作近似标定，不能与前后/左右分量混写。
6. 备注明显走歪、打滑、碰到物体或释放后继续滑动的序号。这类样本保留，但需要单独判断，不用它硬凑比例。

## 收尾时交付的数据

一次发回：完整串口日志，以及16行实际x/y测量（或明确标注的直线距离）。允许直接在纸上按序号记录后转成文字。无需提前计算误差、比例或角度。

如果某条仅报BAD_CMD且没有运动，就重做该序号；若已经运动而DONE缺失，先记录本次实际动作，不为了补DONE重复走。没有ENC的样本暂不能用于比例拟合，可以补一次同序号并注明。

## 后续计算方法

沿请求方向的实际进度d（毫米）：

| 方向 | 实际进度d |
| --- | --- |
| W | x |
| S | -x |
| A | y |
| D | -y |
| Q | (x+y)/sqrt(2) |
| E | (x-y)/sqrt(2) |
| Z | (-x+y)/sqrt(2) |
| C | (-x-y)/sqrt(2) |

斜移d是沿45度指令方向的距离，不能把单轴x/y直接当作斜向路程。同时检查垂直于指令方向的偏移，比例不能修复明显走歪。

每方向分别拟合 d = k × ENC，k单位mm/CNT。两条有效样本可用 k = Σ(ENC×d) / Σ(ENC²)；同时比较短长两条各自d/ENC是否一致。若差别明显超出量尺误差和运动重复波动，只补该方向，不重跑全套。

上层目标距离L毫米换算为请求计数：CNT = round(L/k)。已有固件自动应用刹车提前量，上层不要再减一次。协议继续使用@MOVE,方向,CNT,CNT，例如换算出1050后发送@MOVE,D,1050,CNT；不擅自改已同步的机器协议为MM。

斜移若上层给的是x/y目标，先确定是否为45度斜移；45度情况下斜向距离为sqrt(x²+y²)。任意比例的x/y不能只靠单一Q/E/Z/C方向完成。

## 验证和结束

这16次用于得到第一版物理系数。系数算完后，只对短长比例不一致、明显走歪或最终任务特别关键的方向安排补测。若需要实物精度验收，在已标定范围内选实际会使用的距离检查；公差以任务要求为准，不为追求编码器完全零误差反复调参。

刹车参数不在本轮反复修改，距离系数与刹车提前量分别保存。参数需随最终电池、载荷及地面条件复核，当前不扩展为所有距离或所有地面均已验证。
