# CCD 测距工作台 1.2

本工作台配套当前已烧录的测距标定固件 `CCD-PEAK-RAW-CAL-3.0`。固件使用短坐标命令 `@c0071#@`，返回原始 CCD 最小坐标；距离由电脑端按照 `calibration.csv` 分段线性换算。

当前标定条件为曝光档位 5。默认表包含 18 个点，覆盖 15～100 cm；坐标范围为 814～1203。表外坐标不外推、不钳位，也不作为最大量程回波。

Windows 可直接双击 `CCD_Distance_App_v1_2.exe`；从源码运行可使用项目根目录的 `start_distance_workbench.bat`。

## USB 直连

1. 确认测距 ESP32 正在运行 `CCD-PEAK-RAW-CAL-3.0`，并关闭占用串口的 Thonny 或串口助手。
2. 通过 USB 连接 ESP32，在工作台中选择对应 COM 口并连接。
3. 连接成功后开启激光，使用“测一次”或“连续测量”。
4. 需要核对准确度时，在“尺量距离”中输入同一距离基准下的厘米值。

连接阶段会依次发送 `STOP`、`DEBUG 0`、`LASER 0`、`STATUS`、`EXPOSURE 5`，并再次读取状态。程序只接受版本 `CCD-PEAK-RAW-CAL-3.0`、命令 `@c0071#@` 和已发送曝光 5 的状态。

## LoRa 连接

串口参数为 115200、8 位数据位、无校验、1 位停止位。当前固件默认 `INPUT USB`；需要通过 LoRa 下发命令时，必须先在 USB 终端执行 `INPUT LORA` 或 `INPUT BOTH`，并确认无线模块参数已经一致。

相邻点之间按 CCD 坐标线性插值。例如坐标 910 位于 40 cm/922 与 45 cm/901 之间，换算结果约为 42.86 cm。

距离显示保留两位小数只代表显示格式。标定表只有每个距离的一组代表坐标，当前程序只能给出由 1 个坐标计数引起的局部分辨率估计，不能由此宣称绝对精度或重复精度。

## 记录与标定表

- 曲线默认显示最近 60 次距离，可切换为原始坐标；无效或表外测量在距离曲线上断开。
- 最近 20 次有效坐标显示中位数、极差和样本标准差，用于观察重复性。
- 导出 CSV 保存请求与回复时间、原始坐标、换算距离、参考距离、偏差、标定编号和完整标定点。
- 可导入其他 `distance_cm,ccd_x` CSV；距离必须严格递增，坐标必须严格递减。

建议在未参与标定的距离处进行检查，例如 22、47、72、97 cm，并在不同表面重复采样。光路、焦距、曝光和距离零点变化后，需要重新标定。

## 与旋转扫描的关系

当前已烧录固件只支持静态标定和 `MIN` 测量，不提供 `SYNC`、`START`、`PIX` 及设备采样时间。正式旋转建图必须使用项目中的同步测距固件候选，并保持同一曝光档位 5；完成烧录和实机时序验证前，不能把静态收包时间当作正式扫描角度依据。

## 源码运行

`source/app.py` 是电脑端入口，不应上传到 ESP32。安装 Python 3.10 或更新版本及依赖后运行：

```text
python -m pip install -r requirements.txt
python app.py
```
