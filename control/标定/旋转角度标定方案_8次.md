# 旋转角度标定方案：8次正式采集

适用：当前装好雷达、修复硬件后的小车。目标是获得实用的顺/逆时针角度控制，允许小幅误差；沿用现有Arduino固件，在电脑端实现角度换算与停车补偿。

**使用新增ROTATION_BRAKE=1终端进行本表的原始CNT采集时，先在“旋转补偿”页关闭补偿并保存到电脑。若是在验证停车补偿，则保持开启，按使用说明跑终点500/1000的R/F各一次，此时日志另外记录原终点与下发量。**

## 1. 本轮固定条件

- 使用最终装配、同一种测试地面和同一块电池。确认第四轮能正常工作、编码器不再持续近零。
- 使用本轮提高后的ROT参数：快/中/慢38.4/33.6/28.8 CNT/20ms，起步24，前馈135/130/125，起步前馈150，过渡500ms，PWM90～180。当前整份JSON的CRC为48822。
- 终端点“重新载入文件”→“保存并应用到小车”，确认成功。本轮中途不再调参。若小车断电或重启，重新应用后才能继续；仅重开终端且车未重启不需要重新应用。
- 当前旋转输入是左侧独立的“原地旋转量（CNT）”，不是上方平移距离。R=顺时针，F=逆时针；不发送DEG指令。
- 先确认新参数能稳定起转。如仍有明显起不来或原地空转，先处理运动问题，该趟不用于拟合角度系数。

## 2. 怎样测角度

在固定车身上选一条清楚的车头朝向基准线，例如沿底盘纵向固定的直尺或胶带线；不能使用雷达自身会旋转的部分作为基准。每次记录运动前后这条线的朝向夹角，测车身稳定停下后的实际总转角。

可用地面长参考线配合量角器、大号角度模板，或能清楚看到固定车身基准线的正上方照片。长直尺/长基准线有助于减小人工读数误差。若旋转中心有平移，比较前后两条朝向线的方向，不能把某个车角相对原中心的位移当成旋转角。

每趟都测相对本趟起始朝向的角度。可以人工复位，也可以直接从上趟停下的位置继续，但必须重新记起始方向；R/F往返不会保证自动回到原朝向。记录实际角度，如87°、183°，不要因为目标大约90°或180°就直接填90/180。顺逆方向单列，角度幅值统一填正数。转过180°时按实际转动方向记录总角度，不能填成补角；如转过整圈，记录圈数和剩余角度。

## 3. 直接使用固定CNT

正式两档直接使用500 CNT与1000 CNT，R/F相同，不需要自行估算目标。测实际总角度即可，不要求转到某个指定角度。当前用户实测这两档约30°与52～55°；后续90°及更大角度需要用实际角度指令另验。

## 4. 正式一批8次

每个方向两档，每档重复两次。点击后等本次结束并测量、记录，再发下一次。发生报错或结果不确定的动作保留原记录、标为无效；先确认车辆状态，随后另做一趟并明确序号，不能把它当成功样本。

| 1 | R | 500 | | | |
| 2 | F | 500 | | | |
| 3 | R | 500 | | | |
| 4 | F | 500 | | | |

| 7 | R | 1000 | | | |

备注只需记录有意义的现象：起转困难、明显空转、某轮迟起、车身中心明显跑偏或动作报错。正常可填“正常”。不用手抄四轮计数，终端会自动保存请求CNT、BRAKE_CNT、ENC_CNT及Q1～Q4。

采完一次性交回：填好的本表（可直接编辑本MD）和对应完整日志。日志在`control/参数工具/logs/`。保留失败趟及额外动作，靠时间和序号对应实际测量。

## 5. 数据处理与电脑端接入

R/F分开处理，首先比较同方向、同CNT两次的真实角度，判断重复性；然后结合全部有效样本估计：

- 轮侧角度系数：`k ≈ 最终ENC / 实际角度`，单位CNT/°，多点拟合检查其一致性。
- 停车增量：`最终ENC - BRAKE_CNT`。
- 阈值检查越过量：`BRAKE_CNT - 请求CNT`。旋转当前没有车端提前量，所以此差主要反映到达阈值与实际触发之间的增量。

电脑端初始模型可以写成：`下发CNT ≈ k × 目标角度 - L`，其中L估计的是最终ENC相对原请求CNT的总增量，不能只拿停车增量代替。再用实测“请求CNT—真实角度”关系交叉检查，必要时按两档做简单插值，保留R/F独立参数。缩短下发目标也会改变固件按目标比例划分的速度区间，故最后要用真正的角度指令验证。

目前JSON没有旋转角度系数字段，终端也尚未提供DEG输入；这轮先采数据。获得数据后再把换算和补偿接到电脑端，不能只往现有严格校验的JSON随意增加字段。Arduino固件不需要因此修改。

若同CNT两次真实角度差得很大，先检查对应运动现象，不用继续细调系数掩盖重复性问题。两次接近时直接形成初值，不为一两度继续反复调参。

## 6. 接入后的简短验收

电脑端角度功能接入后，R90°、F90°、R180°、F180°各一次，共4次。检查实际角度及起转稳定性。可暂以约±5°作为实用参考，最终以任务允许偏差为准；这个数是验收参考，不是现有系统已经达到的精度。

如果主要任务需要15°～30°的小角度，再补该实际常用角度R/F各两次；90°/180°的数据不能直接证明很小角度也准确。超出已测范围的大角度同理，只针对实际会用的角度补验。

换地面、改变装配或再次修改ROT速度/前馈后，先重复90°的R/F各一次，看原标定是否仍适用。此次标定不以底盘ENC成功返回代替真实角度测量。
