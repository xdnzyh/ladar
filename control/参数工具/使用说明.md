# 底盘集成终端：按钮与参数编辑窗口

直接双击同目录的 **底盘集成终端.exe**。无需安装额外运行环境或重新烧录。使用当前目录的底盘参数.json；开启前退出占用底盘串口的旧发送器。原来的底盘参数工具_CONFIG1.exe以及start_chassis_parameters.bat仍是命令行入口。

## 日常操作

1. 选择串口，点击“连接并读取”。自动读取95项，核对一致后运动按钮可用；连接不会自动修改车上参数。
2. 左侧输入距离，选择“毫米”或“CNT”，点击一个方向按钮执行一次动作；等待本次结束后才允许下一个动作。方向以车身为参照。点击红色“停止”或按Esc请求停止；现场确认停稳后点击解锁。
3. 右侧在“距离标定 / 运动参数 / 刹车补偿 / 高级参数”中直接修改编辑值。参数名为中文，悬停名称可查看原代码字段名；表格列出允许范围、单位、设备最后读回值。
4. 只改距离系数：点“保存到电脑”，新系数用于后续毫米换算。
5. 修改起步、速度、刹车等执行参数：点“保存并应用到小车”，自动保存文件、更新工具配置、提交并完整读回，无需手工输入LOAD/APPLY/READ。

“读取车上参数”只更新设备值列，不覆盖编辑值；“重新载入文件”读取外部JSON修改；“导出设备配置”先读取设备再导出新文件。保存时自动备份原JSON到旁边backups目录，当前文件若被其他程序改动则提示重新载入，避免覆盖。

未保存编辑、配置不一致、操作进行中或停止未确认时，运动按钮不可用。通信在单个后台线程串行执行，界面保持响应，连点不会排队执行多次运动。断线保留当前终端内的未确认动作状态。车端执行参数仍保存在RAM，重新开电后用“保存并应用到小车”恢复电脑文件中的配置。

底部默认只显示操作摘要；勾选“显示通信明细”可查看后续原始协议行。“打开日志文件夹”查看完整记录。每次启动生成logs/*_terminal.txt及*_terminal_rx.bin，明细始终记录到文件，不受界面开关影响。

源码在源码/CarTerminal.cs，构建入口源码/build_terminal.ps1；加-Test执行离线测试，不打开串口。终端与命令行工具共用CarConfigClient、CarSession及参数表，包含CONFIG_RECOVERY、RESULT_RECOVERY和IDLE_PREFLIGHT。当前界面/模拟通信测试通过，首次实车使用按连接读取、一次短动作核对即可。

# 底盘参数工具 CONFIG1

当前版本标记：`RESULT_RECOVERY=1`、`IDLE_PREFLIGHT=1`。适用于已经烧录 CONFIG1 + RESULT1 的小车。2026-09-10 的空闲握手优化只更新电脑软件，无需再烧录。

## 日常使用

1. 双击本目录 `底盘参数工具_CONFIG1.exe`，选择底盘串口。也可使用项目根目录的 `start_chassis_parameters.bat`。
2. 开电后执行一次 `READ`，完整读取95项并核对与JSON一致；需要提交本地执行参数时用 `APPLY`。
3. 工具在等待输入时自动进行一次 PING。显示“空闲握手已准备，下一条动作可直接发送”后，输入原来的指令，例如 `W 100 MM` 或 `D 700 CNT`。
4. 正常结果显示“完成本次动作，结果校验通过”。若回报丢失或损坏，工具自动只读查询停车快照，运动指令只发送一次。

参数确认状态会缓存；平时每条动作无需重新READ，也无需手动PING。预备握手一次仅供一个动作使用，完成后在下一段空闲时间准备下一次。准备成功后不会定时反复PING。如果输入动作时预备尚未完成，只等待该次握手剩余时间；预备失败则在正式动作前重新握手。

这一优化将通常约0.6秒的动作前握手等待提前到空闲时间；无线传输和车辆起步仍需要时间。准备完成后的直接发送已通过离线时钟测试，实际起步体验以新日志和现场观察为准。

## 命令

- `READ`：读取95项并与本地JSON比较。
- `LOAD`：重新加载编辑后的 `底盘参数.json`，随后用READ/APPLY核对。
- `APPLY`：空闲时提交执行参数，再完整回读；不移动。
- `EXPORT`：导出实际执行参数；距离系数沿用电脑配置。
- `PING`：手动只读握手。
- `LINKTEST`：静止通信自检，16/64/128字节有效内容各测2次。
- `D 100 MM`：电脑按当前方向的距离系数换算为CNT，底盘负责运动与制动。
- `D 700 CNT`：直接使用编码器目标。
- 动作等待/执行中按 `Esc`：请求停止，保持锁定等待现场确认。
- `CONFIRM`：操作者确认车辆已停止后解锁；不补发动作。
- `EXIT`：退出工具。

读取、提交、手动自检等操作会先处理已有预备握手，避免命令交错；检测到启动、急停或通信结果不确定时，预备状态失效。

## 参数与日志

保留exe旁的 `底盘参数.json`。距离系数由电脑换算后发CNT，不使用固件内置MM系数。执行参数位于车上RAM，断电回到固件默认值；断电重开后重新READ/APPLY。参数定义和范围见父目录《CONFIG1参数表.md》《运行时参数接口_CONFIG1_交接.md》。

日志自动保存在本工具旁的 `logs`，包括带时间戳的事件日志和原始接收字节。启动本工具前关闭占用同一串口的其他程序。

源码在 `源码` 目录；运行 `源码/build.ps1` 可重新编译，运行exe附加 `--test` 可执行离线测试，不打开串口。普通使用无需安装Python或编译工具。受保护运动协议见父目录《结果恢复协议_RESULT1.md》。

## CONFIG_RECOVERY=1（2026-09-10）

当前参数工具已支持配置丢报恢复。读取I/G与同事务暂存B/S在超时时最多重试2次；CRC和参数字段继续严格校验。最终提交C只发送一次，应答丢失后自动完整读回核对实际配置，确认95项与目标一致才允许继续运动。持续失败或设备明确拒绝时仍提示错误。该功能只更新本exe，无需重新烧录。
