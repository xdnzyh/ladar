# 底盘集成终端：按钮与参数编辑窗口

直接双击同目录的 **底盘集成终端.exe**。无需安装额外运行环境或重新烧录。使用当前目录的底盘参数.json；开启前退出占用底盘串口的旧发送器。原来的底盘参数工具_CONFIG1.exe以及start_chassis_parameters.bat仍是命令行入口。

## 日常操作

### 原地旋转：直接输入度数（ROTATION_DEG=1）

左侧平移九宫格下方是独立的旋转输入，默认30°。选择“度(°)”，输入角度（0.1～360°），点击“顺时针 R”或“逆时针 F”执行一次；切换“CNT”可继续输入编码器终点，默认记忆500CNT。两种输入分别记忆数值，与上方平移毫米/CNT选择无关。

电脑按实测初值换算：R的20°对应终点500、50°对应1000；F的20°对应终点500、47°对应1000。两点之间线性插值，大于第二点延续该斜率；低于第一点按0到第一点的比例估算。换算为终点CNT后只减一次停车提前量，再用现有受保护CNT协议下发。默认参数下R90°→终点1667→下发1522；F90°→终点1796→下发1651。

这是当前实测20～50°附近的粗标定。90°、180°及小角度属于未验证估算，日志记EXTRAPOLATED=1；动作完成只代表对应编码器运动完成，不将编码器结果冒充真实角度测量。首次直接用R30°、F30°观察；之后按实际会用的90°等角度验证即可，不再要求整批重测。

在“旋转标定/补偿”页可直接修改4个实测角度（终点500/1000CNT对应值）及R/F提前量，点击“保存到电脑”生效。角度字段和补偿都保存在原`旋转停车补偿.json`，schema2；新版仍能读schema1并使用本轮初值，保存时升级。关闭补偿用于CNT原始测试，度控制会要求先开启补偿，避免混用补偿前后的标定。

当前旋转停车补偿为R/F各145CNT，默认开启，已完成500/1000CNT的首轮实车验证。在“旋转标定/补偿”页调整两方向提前量或开关，再点“保存到电脑”即可生效，不需要提交车端。参数保存在同目录`旋转停车补偿.json`，重开终端仍保留；分发新版exe时须同时带上此文件及原`底盘参数.json`。该文件仅集成终端使用，命令行及Python导航尚未接入旋转补偿与角度换算。

开启时下发CNT=输入终点−提前量。例如500下发355，1000下发855。车端ACK/RESULT中的REQ仍是实际下发量，原始结果保持不变；电脑另记录`ROTATION_REQUEST`和`ROTATION_STOP`，列出GOAL_CNT、WIRE_CNT、LEAD、ENC_CNT及STOP_ERROR（最终ENC−输入终点）。界面“已完成”表示协议动作完成，并显示真实停车误差，不代表误差已达某个验收精度。

小目标若不大于提前量，会提示且不发送，不自动夹为1CNT。较大目标继续使用该提前量，不在区间外悄悄取消补偿；145CNT主要依据原下发500/1000两档数据，大小目标的效果仍需实测。关闭补偿后输入值原样下发，适用于原始CNT标定。

本轮验证：保持新ROT动力参数（此前已应用的整组CRC48822），终点500下R一次、F一次，再终点1000下R一次、F一次，共4次；分别等动作完成后再发下一次。无需重新量角度，先看停车误差与起转。原来下发500最终约640，补偿后同样输入500会转得少一些，目标是最终ENC接近500。此初值尚待实车验证。

空闲握手、CRC/编号校验、丢报只读恢复、停止/Esc、未确认锁定沿用，旋转按钮与平移按钮一样不排队。日志仍保存到同一logs目录，原始R/F的BRAKE_CNT、ENC_CNT及Q1～Q4均保留。

原地旋转的速度、起步、前馈和PWM参数在“运动参数”页中的“原地旋转”条目。动力参数与横移同档，仍需应用到小车才生效，车端断电后恢复固件启动值。旋转补偿与度数入口只改电脑软件；Arduino固件、当前动力JSON及自动导航保持原样。

### 平移与参数编辑

1. 选择串口，点击“连接”，即可使用运动按钮。默认使用车上现有执行参数，不自动读取或应用95项参数；需要同步时由你点击相应按钮。空闲时保留短PING握手，缩短点击运动后的等待。
2. 左侧输入距离，选择“毫米”或“CNT”，点击一个方向按钮执行一次动作；等待本次结束后才允许下一个动作。方向以车身为参照。点击红色“停止”或按Esc请求停止；现场确认停稳后点击解锁。
3. 右侧在“距离标定 / 运动参数 / 刹车补偿 / 高级参数”中直接修改编辑值。参数名为中文，悬停名称可查看原代码字段名；表格列出允许范围、单位、设备最后读回值。
4. 只改距离系数：点“保存到电脑”，新系数用于后续毫米换算。
5. 修改起步、速度、刹车等执行参数：点“保存并应用到小车”，自动保存文件、更新工具配置、提交并完整读回，无需手工输入LOAD/APPLY/READ。

“读取车上参数”只更新设备值列，不覆盖编辑值；“重新载入文件”读取外部JSON修改；“导出设备配置”先读取设备再导出新文件。保存时自动备份原JSON到旁边backups目录，当前文件若被其他程序改动则提示重新载入，避免覆盖。

未保存编辑、操作进行中或停止未确认时，运动按钮不可用。未读取参数、读取失败、电脑与设备参数不一致均不强制同步、不锁定运动按钮。“保存到电脑”只保存本地修改；车端执行参数在点击“保存并应用到小车”后更新，毫米换算使用电脑保存的距离系数。

通信在单个后台线程串行执行，界面保持响应，连点不会排队执行多次运动。断线保留当前终端内的未确认动作状态。车端执行参数仍保存在RAM，重新开电后使用固件启动值；如果要恢复此前调好的电脑配置，手动点击一次“保存并应用到小车”。连接本身不恢复参数。

日志标记 `MANUAL_CONFIG_SYNC=1`。动作记录中的 `FILE_CRC` 表示电脑文件执行参数，`DEVICE_CRC` 表示当前连接中有效的设备读回记录，未核对时明确记录“未核对”。不将本地文件值当作车端实际值。此操作方式适用于集成终端，下面命令行工具的READ/APPLY流程保持原样。

底部默认只显示操作摘要；勾选“显示通信明细”可查看后续原始协议行。“打开日志文件夹”查看完整记录。每次启动生成logs/*_terminal.txt及*_terminal_rx.bin，明细始终记录到文件，不受界面开关影响。

源码在源码/CarTerminal.cs，构建入口源码/build_terminal.ps1；加-Test执行离线测试，不打开串口。终端与命令行工具共用CarConfigClient、CarSession及参数表，包含CONFIG_RECOVERY、RESULT_RECOVERY和IDLE_PREFLIGHT。手动同步模式已经通过模拟通信测试，待实车使用确认。

# 底盘参数工具 CONFIG1

当前版本标记：`RESULT_RECOVERY=1`、`IDLE_PREFLIGHT=1`。适用于已经烧录 CONFIG1 + RESULT1 的小车。2026-09-10 的空闲握手优化只更新电脑软件，无需再烧录。

## 日常使用

1. 双击本目录 `底盘参数工具_CONFIG1.exe`，选择底盘串口。也可使用项目根目录的 `start_chassis_parameters.bat`。
2. 开电后执行一次 `READ`，完整读取95项并核对与JSON一致；需要提交本地执行参数时用 `APPLY`。
3. 工具在等待输入时自动进行一次 PING。显示“空闲握手已准备，下一条动作可直接发送”后，输入原来的指令，例如 `W 100 MM` 或 `D 700 CNT`。
4. 正常结果显示“完成本次动作，结果校验通过”。若回报丢失或损坏，工具自动只读查询停车快照，运动指令只发送一次。

参数确认状态会缓存；平时每条动作无需重新READ，也无需手动PING。预备握手一次仅供一个动作使用，完成后在下一段空闲时间准备下一次。准备成功后不会定时反复PING。如果输入动作时预备尚未完成，只等待该次握手剩余时间；预备失败则在正式动作前重新握手。

这一优化将通常约0.6秒的动作前握手等待提前到空闲时间；无线传输和车辆起步仍需要时间。准备完成后的直接发送已通过离线时钟测试，实际起步体验以新日志和现场观察为准。

## 命令

- `READ`：读取95项并与本地JSON比较。
- `LOAD`：重新加载编辑后的 `底盘参数.json`，随后用READ/APPLY核对。
- `APPLY`：空闲时提交执行参数，再完整回读；不移动。
- `EXPORT`：导出实际执行参数；距离系数沿用电脑配置。
- `PING`：手动只读握手。
- `LINKTEST`：静止通信自检，16/64/128字节有效内容各测2次。
- `D 100 MM`：电脑按当前方向的距离系数换算为CNT，底盘负责运动与制动。
- `D 700 CNT`：直接使用编码器目标。
- `R 250 CNT`：原地顺时针旋转，目标250编码器计数。
- `F 250 CNT`：原地逆时针旋转，目标250编码器计数。R/F仅接受CNT；MM和DEG不接受。
- 动作等待/执行中按 `Esc`：请求停止，保持锁定等待现场确认。
- `CONFIRM`：操作者确认车辆已停止后解锁；不补发动作。
- `EXIT`：退出工具。

读取、提交、手动自检等操作会先处理已有预备握手，避免命令交错；检测到启动、急停或通信结果不确定时，预备状态失效。

## 参数与日志

保留exe旁的 `底盘参数.json`。距离系数由电脑换算后发CNT，不使用固件内置MM系数。执行参数位于车上RAM，断电回到固件默认值；断电重开后重新READ/APPLY。参数定义和范围见父目录《CONFIG1参数表.md》《运行时参数接口_CONFIG1_交接.md》。

日志自动保存在本工具旁的 `logs`，包括带时间戳的事件日志和原始接收字节。启动本工具前关闭占用同一串口的其他程序。

源码在 `源码` 目录；运行 `源码/build.ps1` 可重新编译，运行exe附加 `--test` 可执行离线测试，不打开串口。普通使用无需安装Python或编译工具。受保护运动协议见父目录《结果恢复协议_RESULT1.md》。

## CONFIG_RECOVERY=1（2026-09-10）

当前参数工具已支持配置丢报恢复。读取I/G与同事务暂存B/S在超时时最多重试2次；CRC和参数字段继续严格校验。最终提交C只发送一次，应答丢失后自动完整读回核对实际配置，确认95项与目标一致才允许继续运动。持续失败或设备明确拒绝时仍提示错误。该功能只更新本exe，无需重新烧录。
